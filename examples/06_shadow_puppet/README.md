# 工位回血

让摄像头拍到头、肩和双手，小电就会跟着你动。展翅、老鹰、挥手、滑雪、弹琴、跳跃、转头、点头八种动作均可在浏览器单练或连闯。犀牛派还会监测工位久坐，在需要活动时提醒你。

## 先玩一局

首次打开大厅会播放 54.5 秒的像素街机序章《夜班行动》。开发者和小电从天台出发，沿途用八种动作点亮八座信号站。片中展示游戏的摄像头操作、真实关卡画面和整轮战报。片尾可进入体感八关连闯，也可选择键盘或触屏玩法。片头可跳过、重播或展开文字版，打开单关邀请则直接进入挑战。片头、八个关卡和大厅的 8-bit 配乐以及命中、失误、过关等音效均使用 Runway 制作，媒体随游戏离线提供。右上角的扬声器可切换音乐和音效。

在本目录执行 `python3 -m http.server 8080 --directory web`，在这台电脑的浏览器打开 `http://localhost:8080/`。在「挑战卡带」选择摄像头体感和想玩的关卡，看完动作示范，再点「开启摄像头玩这关」。首页「体感八关连闯」会按下表顺序开局。单关限时 45 秒，八关连闯限时 120 秒，有效动作时间在失去跟踪时暂停。手机开启自身摄像头需要用 HTTPS 地址打开。动作模型随网页提供，摄像头画面在本机处理。

| 本机体感关卡 | 动作 | 目标 |
| --- | --- | --- |
| 天台展翅 | 双臂向外平举，双腕抬到肩高 | 保持进度达到 5 秒 |
| 老鹰起飞 | 展开双臂，同时抬高再压低 | 完整扇翅 8 次 |
| 月台挥手 | 抬起一只手，在脸旁左右挥动 | 换向挥手 10 次 |
| 雪岭穿梭 | 向旗子所在的一侧倾身 | 碰到 6 面旗 |
| 落日合奏 | 掌心朝镜头，两手各占画面一侧。轻弯黄键点名的那根手指，再伸直 | 命中 8 个黄键 |
| 仙人掌跳跃 | 遇到障碍时坐姿轻挺，让双肩一起上提再落下 | 越过 5 个仙人掌 |
| 左右转头 | 双肩朝前，向一侧转脸，再回正 | 左右各 3 次 |
| 节拍点头 | 保持肩部稳定，低头再抬起回正 | 完成 6 次 |

片头播放到小游戏时，可以点「试玩」直接进入画面里的那一关，也可以拖动进度条找回想玩的镜头。

离线时双击 [web/index.html](web/index.html)，大厅的八张卡带都支持键盘和触屏。点卡带即可选关，也可以用 Tab 聚焦卡带、方向键选择、Enter 进入。点「先试按键」练一个动作，再按「开始计分」。触屏可直接点按游戏按键，弹琴也可以滑过琴键。键盘按 P 暂停或继续。单关通关可直接进入下一关，或留下再玩一遍。

体感舞台的画面下方显示当前动作和完成量。手腕或脸离开取景范围时，提示会指出需要重新入镜的部位。暂时无法使用摄像头时，可以从同一页切换到这张卡带的键盘或触屏玩法。

「落日合奏」使用随游戏提供的 MediaPipe Hand Landmarker，每只手识别 21 个关键点。面朝镜头，左右手各管五键，两根拇指对应中间相邻的琴键。像素舞台与摄像头视图都能看到手部骨骼，黄色标出目标手指。按错会响起实际弹奏的音，目标保留。目标手离开画面会暂停计时。键盘和触屏版沿用四键节奏玩法。[MediaPipe 手部关键点说明](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker)

结算页可生成 800 × 1000 像素的 PNG 战报。通过可访问的 HTTP(S) 地址打开时，街机邀请链接包含关卡和目标分数。邀请者和好友需要都能访问该地址。本机文件或 localhost 试玩会提供邀请文案。最近 15 局可在「我的战绩」回看。

## 在犀牛派上运行

将完整的 `examples/` 放到装有 AidLite、配套模型和 USB 摄像头的开发板，进入 `06_shadow_puppet/` 运行：

```bash
python3 game.py                       # 25 分钟提醒；坐姿不对额外扣血
python3 game.py --demo                # 45 秒就催，录像用
python3 game.py --interval-min 15 --round-acts 6
python3 game.py --round-acts 8          # 每轮玩到全部八种动作
python3 render_probe.py --out /tmp/ui  # 不用人也能渲染每一屏，核对排版
```

`http://<板子IP>:8090/`  状态：`/status`

## 板端画面

| 阶段 | 画面 |
| --- | --- |
| 像素舞台 | 打开板端首页默认进入。小电跟随肩、肘、腕和头部运动，旗门、琴键、障碍和动作进度与板端判定同步 |
| 摄像头 | 在舞台顶部切换，查看原始摄像头叠加骨架、识别指标和动作提示 |
| 回合结束 | 显示本轮成绩，点击「查看战报」可保存图片；回合数据保存在当前浏览器 |

## 流程

满 25 分钟（或 HP 被坐姿扣光）弹提醒，展翅或举手开始。**每组 2 分钟**，每个动作一屏，过了 challenge 才算过关，自动跳下一屏，最后出总结。

| 动作 | challenge |
| --- | --- |
| 展翅 | 双臂撑满 5 秒 |
| 老鹰 | 双臂向两侧展开，一起抬高再压低，扇翅 8 次 |
| 挥手 | 一只手举到肩高，左右交替挥，送走 10 个人 |
| 滑雪 | 面朝前，头和上身向两侧倾，碰 6 面旗并避开松树 |
| 弹琴 | 张开双手，对应手指向下按黄键再抬起，命中 8 次；手部模型加载失败时改用手腕选键、下压 |
| 跳跃 | 仙人掌靠近时坐着轻挺上身，落回坐姿再起跳，越过 5 个 |
| 转头 | 向屏幕左、右各转 3 次，每次回正后再转 |
| 点头 | 双肩保持稳定，低头再抬回 6 次 |

## 模型

| 用途 | 模型 |
| --- | --- |
| 上半身姿态 | `pose_detect_track/models/pose_landmark_upper_body.tflite`（TFLite GPU） |
| 手部 21 点 | `hand_track/models/palm_detection.tflite` + `hand_landmark.tflite`（只在弹琴那一屏加载） |
| NPU 底栏 | `cutoff_yolov5s_...qnn236.ctx.bin`（QNN236 DSP 脉冲） |

坐姿评分看四项：低头前伸、塌坐、歪肩、离屏太近。回合结束后会按当时的坐姿重新标定基线。
