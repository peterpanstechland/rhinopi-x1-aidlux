# 工位回血

让摄像头拍到头、肩和双手，小电就会跟着你动。体感舞台提供八种动作示范。本机摄像头可玩连续三关，犀牛派可玩完整八种动作，并在久坐时提醒你活动。

## 先玩一局

在本目录执行 `python3 -m http.server 8080 --directory web`，在这台电脑的浏览器打开 `http://localhost:8080/`。进入「体感舞台」，选动作看示范，然后点「开启摄像头闯三关」并允许相机。手机开启自身摄像头需要用 HTTPS 地址打开。动作模型随网页提供，摄像头画面在本机处理。

| 本机体感关卡 | 动作 | 目标 |
| --- | --- | --- |
| 天台展翅 | 双臂向外平举，双腕抬到肩高 | 保持进度达到 5 秒 |
| 雪岭穿梭 | 向旗子所在的一侧倾身 | 碰到 6 面旗 |
| 落日合奏 | 左右移动手腕，对准十键中的亮键，下压再抬起 | 命中 8 个黄键 |

离线时双击 [web/index.html](web/index.html)，大厅的三张卡带支持键盘和触屏。展翅按空格抓节拍，滑雪按方向键换道，弹琴按 A、S、D、F，触屏点对应按键。

结算页可生成 800 × 1000 像素的 PNG 战报。通过可访问的 HTTP(S) 地址打开时，街机邀请链接包含关卡和目标分数。邀请者和好友需要都能访问该地址。本机文件或 localhost 试玩会提供邀请文案。最近 15 局可在「我的战绩」回看。

## 在犀牛派上运行

将完整的 `examples/` 放到装有 AidLite、配套模型和 USB 摄像头的开发板，进入 `06_shadow_puppet/` 运行：

```bash
python3 game.py                       # 25 分钟提醒；坐姿不对额外扣血
python3 game.py --demo                # 45 秒就催，录像用
python3 game.py --interval-min 15 --round-acts 6
python3 render_probe.py --out /tmp/ui  # 不用人也能渲染每一屏，核对排版
```

`http://<板子IP>:8090/`  状态：`/status`

## 板端画面

| 阶段 | 画面 |
| --- | --- |
| 像素舞台 | 打开板端首页默认进入。小电跟随肩、肘、腕和头部运动，旗门、琴键、障碍和动作进度与板端判定同步 |
| 摄像头 | 在舞台顶部切换，查看原始摄像头叠加骨架、识别指标和动作提示 |
| 回合结束 | 显示本轮成绩，点击「查看战报」可保存图片；回合数据保存在当前浏览器 |

## 流程

满 25 分钟（或 HP 被坐姿扣光）弹提醒，展翅或举手开始。**每组 2 分钟**，每个动作一屏，过了 challenge 才算过关，自动跳下一屏，最后出总结。

| 动作 | challenge |
| --- | --- |
| 展翅 | 双臂撑满 5 秒 |
| 老鹰 | 双臂向两侧展开，一起抬高再压低，扇翅 8 次 |
| 挥手 | 一只手举到肩高，左右交替挥，送走 10 个人 |
| 滑雪 | 面朝前，头和上身向两侧倾，碰 6 面旗并避开松树 |
| 弹琴 | 张开双手，对应手指向下按黄键再抬起，命中 8 次；手部模型加载失败时改用手腕选键、下压 |
| 跳跃 | 仙人掌靠近时坐着轻挺上身，落回坐姿再起跳，越过 5 个 |
| 转头 | 向屏幕左、右各转 3 次，每次回正后再转 |
| 点头 | 双肩保持稳定，低头再抬回 6 次 |

## 模型

| 用途 | 模型 |
| --- | --- |
| 上半身姿态 | `pose_detect_track/models/pose_landmark_upper_body.tflite`（TFLite GPU） |
| 手部 21 点 | `hand_track/models/palm_detection.tflite` + `hand_landmark.tflite`（只在弹琴那一屏加载） |
| NPU 底栏 | `cutoff_yolov5s_...qnn236.ctx.bin`（QNN236 DSP 脉冲） |

坐姿评分看四项：低头前伸、塌坐、歪肩、离屏太近。回合结束后会按当时的坐姿重新标定基线。
