# 官方资料地图

下载工具看门户，按步骤看文档中心，X1 专属优先犀牛派文档。论坛只用来排错，不替代官方步骤。

## 开发者门户

选产品、下工具、看架构图。

| 页面 | 用途 |
| --- | --- |
| [软件架构概述](https://developer.aidlux.com/software/architecture) | 系统 → SDK → 模型广场整条工具链 |
| [犀牛派 X1 软件页](https://developer.aidlux.com/software/x1) | 规格、Android 镜像入口 |
| [犀牛派 X1 硬件页](https://developer.aidlux.com/hardware/x1) | 对外介绍、购买 / 规格 |
| [PC 端调试工具](https://developer.aidlux.com/software/debug_tool) | ADB、QPST、USB 驱动、Aid 调用工具、QtScrcpy |
| [AidLite / AidStream / AidCV / AidGen](https://developer.aidlux.com/software/aidlite) | SDK 总览，细节跳文档中心 |

说明：X1 软件页上 AidLux 安装包可能写「请联系我们」。**整包和 AidLux 镜像以文档中心镜像页为准。**
