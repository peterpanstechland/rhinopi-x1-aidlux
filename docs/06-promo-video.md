# 工位回血宣传片：拍摄与剪辑

古怪一点，有故事，椅子品牌只留空位、不露货。正片约 70 秒，再压一条 28 秒狠剪。游戏怎么跑看 [工位回血](05-shadow-puppet.md) 和 [examples/06_shadow_puppet](../examples/06_shadow_puppet)。

## 一句话故事

腰在报警，椅子不像椅子，那把人体工学椅又不在场——于是用阿加犀犀牛派 X1 给工位写了个回血的。

不认识赞助方的人，只觉得在讲腰和破凳；对得上号的人，对上那块空地。两边都成立再发。

## 口播四句

1. 这段时间腰好痛，不知道为啥。
2. 嗯……可能是缺了一把清——的人体工学椅吧。
3. 好吧，没有整把……闲的人体工学椅，怎么办呢。
4. 于是我用阿加犀犀牛派 X1，做了这个。椅子以后再说，血先回了。

「清」和「闲」拆开说，中间用切断接上。不要完整念品牌全称当口播广告。

## 空位怎么留（不露货）

给椅子品牌留位置，但画面里不能出现他们的东西。

| 通道 | 拍 / 剪什么 | 不要出现 |
| --- | --- | --- |
| 画面 | 空地、空墙、椅形剪影；搜索框只打「清」 | logo、包装、官图、整椅、别人家的椅子海报 |
| 声音 | 「清——」被切断，再补「……闲的」 | 完整品牌名当广告口播 |
| 字幕 | `清__`、光标闪；片尾可淡写「那把椅子的位置，先空着。」 | 品牌全称、型号、价格、购买链接 |

空位侧机从片头到片尾用**同一构图**，不要换焦距和高度。片头、审凳、片尾三次调用同一段空镜。

## 机位

四个就够。一部手机按点位锁死轮拍即可。同时最多开两台：正面 + 空位，或侧面全身 + 录屏。

| 机位 | 放哪 | 负责哪几段 | 锁死要点 |
| --- | --- | --- | --- |
| 1. 正面胸像 | 屏幕对面，略高于眼 | 捂腰、口播、「清——」切断、看见板子 | 和 C920 错开，别两台叠在脸正中 |
| 2. 桌面斜俯 | 侧上方 45°，俯看桌 | 板子、插 C920、敲「清」、钱包三剪 | 框住 X1 + 键鼠，椅子不要入画 |
| 3. 空位侧机 | 工位侧面，破凳和空地同一画幅 | 审凳、空地半秒、片尾空位还在 | 整条片子同一构图；框里不要出现任何品牌椅 |
| 4. 录屏 | 电脑或板子网页，不是相机 | Steve 捂腰、扣血、老鹰、月台挥手、总结 | `--demo` 录；和正面胸像对得上同一动作 |

可选第五机位：更远的侧面全身，扇翅膀、挥手时人和屏幕同框。

C920 只给游戏当 LIVE，不当宣传主机位，避免自拍畸变。

桌上够用的东西：犀牛派 X1、C920、你自己的破椅子、那块空地、手机（只拍出「清」）。

## 拍摄顺序

换位越少越好。建议按这个顺序拍，口播可以每句多录两条。

1. **空位侧机先锁死**，拍一段纯空地（至少 5 秒），再拍审凳（踢轮子、拍靠背、拎靠垫）。不要收三脚架。
2. **正面胸像**：四句口播 + 捂腰 + 看见板子。
3. **桌面斜俯**：X1 特写、插 C920、搜索只打「清」、钱包一闪。
4. **录屏 + 正面（或侧面全身）对拍游戏**：坐姿扣血、老鹰、月台挥手、总结。滑雪、转头当备用 B-roll。
5. 空位机位最后再拍 3 秒同一构图，给片尾用。

「清——」切断可以现场做：说到「清」停住，拔一下 USB，或等游戏弹出「人不在工位」，再接「——的人体工学椅吧」。

## 游戏怎么录

```bash
cd ~/rhinopi-lab/examples/06_shadow_puppet
python3 game.py --demo
```

浏览器打开 `http://<板子IP>:8090/`。`--demo` 大约 45 秒就催，适合录像；正式 25 分钟坐等不要拿来拍。

正片游戏镜头只留四段，不要把六关都报完：

1. 坐姿分往下掉、HP 被扣
2. 老鹰：工位扇翅膀，云往下冲
3. 月台挥手：对着一排小人告别
4. 总结屏

弹琴、椅上颠各偷一秒可以；滑雪、转头当备用。

## 70 秒分镜

| 时间 | 主画面 | 叠一下 | 剪法 |
| --- | --- | --- | --- |
| 0–6 | 录屏：Steve 捂腰掉血 | 1 秒切你同一姿势 | 对齐那声闷响再切 |
| 6–18 | 空位侧机：审凳 | 正面：踢轮子、拍靠背 | 「清——」处硬切 USB /「人不在工位」 |
| 18–30 | 空地同一构图，多停 | 斜俯：只打出「清」；钱包一闪 | 「闲的」只听，不给字幕全称 |
| 30–40 | 斜俯：X1 亮着 | 正面：「于是我用……做了这个」 | 插 C920 用动作切，不要溶解 |
| 40–48 | 录屏：坐姿扣血 | 正面塌坐 | HP 掉一格切一刀 |
| 48–56 | 录屏：老鹰 | 有侧面全身就插 1 秒 | 云往下冲那下切你的手臂 |
| 56–62 | 录屏：月台挥手 | 正面挥手 | 对上「再见！」再切 |
| 62–70 | 总结屏 | 空位原构图还在，淡出 | 字幕只出游戏名、X1、GitHub |

开场不要先拍板子。空地那半秒真的静半秒。

## 剪辑

一部手机拍的，剪映就够。建两个工程：`工位回血_70s`、`工位回血_28s`。28 秒从 70 秒另存，不要两边同时改。

| 轨 | 放什么 |
| --- | --- |
| V1 | 录屏（游戏） |
| V2 | 正面胸像（口播主画面） |
| V3 | 空位侧机（审凳、空地、片尾） |
| V4 | 桌面斜俯（板子、插线、搜「清」） |
| A1 | 口播（正面那条的声） |
| A2 | 现场：椅响、USB、键盘 |
| A3 | 极轻底噪或 8-bit 一点点，别抢词 |

先按上面 8 段粗剪，口播不断句，每段只用一个主画面。再改节奏：

- 四句口播保持完整，句与句之间最多半秒气口
- 「清——」切断要干脆，接完立刻说「——的人体工学椅吧」
- 游戏每段一句动作 + 一个反馈，同一关不超过 4 秒
- 转场只用直切

屏幕上只允许这些字：`工位回血`、`犀牛派 X1`、GitHub 地址、搜索框里的 `清`、片尾淡的「那把椅子的位置，先空着。」

口播用正面轨。桌面、空位的环境声只在切断、「插 USB」、椅响三处抬起来。

## 28 秒狠剪

从 70 秒工程另存，只留 6 块：

1. Steve 捂腰 = 你捂腰
2. 「缺了一把清——」切断
3. 空地（还是那一格）
4. 「没有。那就犀牛派 X1。」+ 插线
5. 老鹰 1 秒 + 挥手 1 秒
6. 「工位回血。」空地还在

## 导出

- 正片：1080p、30fps（像素界面不要硬插 60）
- 竖版 1080×1920 再裁一版：**空位和板子不要裁掉**，人脸可以略偏
- 码率给足，像素界面经不起糊

先出能把故事讲完的 70 秒，自己看一遍：不认识那把椅子的人只看到腰和破凳；对得上号的人对上空地。两边都成立再压 28 秒。
